# Roadmap

## Prioritas 1

- Face anti-spoofing atau liveness detection.
- Kalibrasi threshold berbasis dataset sekolah.
- Kebijakan retensi otomatis.
- Observability dan alerting.
- Pengujian end-to-end pada tablet target.

## Prioritas 2

- Badge QR dan pencetakan label.
- Notifikasi WhatsApp kepada pegawai tujuan.
- Multi-campus dengan tenant isolation.
- Appointment dan pre-registration.
- Sinkronisasi data pegawai.

## Prioritas 3

- Integrasi CCTV dengan proses hukum dan privasi terpisah.
- Aplikasi admin seluler.
- Vector database terpisah setelah kebutuhan skala terbukti.
